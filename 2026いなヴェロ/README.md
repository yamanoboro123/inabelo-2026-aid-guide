# 2026 いなヴェロ｜エイド巡りガイド

`index.html` を GitHub Pages で公開するための静的ページです。

## GitHub Pages で公開

リポジトリ直下の `index.html` がこのページへ自動転送します。GitHub Pagesでは **Settings → Pages → Deploy from a branch** を選び、`main` ブランチの `/ (root)` を指定します。

GoogleマップURLは、リポジトリ直下の `MAP_URLS.md` にまとめてから `index.html` の `stationData` へ反映します。URL未登録の間はページに「地図リンク準備中」と表示され、GPXボタンは無効になります。
